# Мапа ГВГ (Perfect World)

Інтерактивна мапа поля бою ГВГ: стрілецькі вежі, стражники на стінах, сторожові вежі, катапульти,
кристали, прив'язки, радіуси атаки, рельєф, а також плани атаки й оборони з етапами.

Сайт: https://arsvrk.github.io/gvg-map/

Плани клану зберігаються в Google-таблиці; доступ за паролем, який дає лідер клану.
